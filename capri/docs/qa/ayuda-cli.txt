DESCRIPCIÓN
  Interfaz de línea de comandos de Capri

USO
  capri <subcomando> [opciones] [<directory>]

ARGUMENTOS
  directory string    Directorio donde iniciar Capri (opcional)

OPCIONES
  --standalone            Ejecutar con un servidor privado en lugar del servicio en segundo plano
  --server string         Conectar a una URL de servidor en lugar del servicio en segundo plano
  --auto                  Aprobar automáticamente los permisos no rechazados explícitamente
  --continue, -c          Continuar la última sesión
  --session, -s string    ID de la sesión que se retomará o creará si no existe
  --prompt string         Mensaje inicial

OPCIONES GLOBALES
  --help, -h                                                          Mostrar la ayuda
  --version, -v                                                       Mostrar la versión
  --wizard                                                            Iniciar el asistente de un comando
  --completions <bash|zsh|fish|sh>                                    Print shell completion script (opciones: bash, zsh, fish, sh)
  --log-level <all|trace|debug|info|warn|warning|error|fatal|none>    Sets the minimum log level (opciones: all, trace, debug, info, warn, warning, error, fatal, none)
  --print-logs                                                        Mostrar registros en stderr (los del servidor requieren --standalone)

SUBCOMANDOS
  upgrade, update    Actualizar OpenCode a la última versión o a una versión específica
  uninstall          Desinstalar Capri conservando sesiones, configuración y estado
  acp                Iniciar un servidor Agent Client Protocol
  api                Enviar una solicitud al servidor en ejecución
  debug              Herramientas de depuración y diagnóstico
  auth               administrar integraciones y credenciales
  mcp                Administrar servidores MCP (Model Context Protocol)
  plugin             Administrar complementos
  models             Listar todos los modelos disponibles
  stats              Mostrar estadísticas de uso para compartir
  mini               Iniciar la interfaz interactiva mínima
  run                Ejecutar Capri con un mensaje
  session            Administrar sesiones
  service            Administrar el servidor en segundo plano
  reload             Recargar configuración
  pair               Mostrar enlaces de un solo uso para vincular un navegador o aplicación
  serve              Iniciar la API v2 y el servidor web
